# エビ色ブリーダー

ミナミヌマエビを繁殖させて色を作り、売って水槽を増やし、図鑑を埋める携帯ゲーム。
依存ライブラリなし（HTML5 Canvas + ES Modules）。通信なし、保存は端末内（IndexedDB）。

## 起動

```bash
node serve.cjs
```

http://localhost:15310 を開く。スマホ幅で見るのが前提。

## テスト

```bash
npm test
```

`js/genetics.js` と `js/sim.js` は DOM に触らない純粋関数なので node で直接テストする。

## 構成

| ファイル | 役割 |
|---|---|
| `js/genetics.js` | 遺伝（色相・発色・模様の3対、輝の突然変異、隠し色）、図鑑キー、名前 |
| `js/sim.js` | 時間進行（汚れ・餌・水温・寿命・孵化）、繁殖条件、水槽の増設と移動、初期状態 |
| `js/economy.js` | 価格と出荷 |
| `js/visitors.js` | 買い付け客（1〜2時間おきに来て40分滞在、相場の1.5〜3.3倍で買う、評判Lv） |
| `js/river.js` | 川への遠征（行き先3つ、色ごとの得意、カード生成、ワイルド個体、素材の定義） |
| `js/state.js` | 保存・読み込み（IndexedDB → localStorage）、セーブ版管理、エラー記録 |
| `js/assets.js` | エビ画像32枚の読み込み |
| `js/render.js` | 水槽の Canvas 描画とタップ判定 |
| `js/ui.js` | 画面（店舗 / 水槽詳細 / 個体カード / 繁殖 / 出荷 / 図鑑 / ショップ / 新色発見） |
| `js/main.js` | 起動、ループ、遷移、イベント処理 |
| `assets/shrimp/` | 透過PNG（r1〜g5 = 色×★段階、h_* = 隠し色、s_* = 状態） |

## 時間の設計（実時間）

- 抱卵→孵化: 4時間（最初の1回だけ2分）
- 稚エビ→成体: 12時間
- 寿命: 10日
- （2026-09-19に 8h/24h/14d から短縮。「今日組んだ子が明日から使える」1日1世代のテンポ）
- アプリを閉じている間も進む（上限24時間）
- 買い付け客: 開始5分後に最初の客、以後1〜2時間おき、滞在40分。汚れ80%以上の水槽があると来ない
- 抱卵の見守り: 抱卵期間を4段階に分け、各段階で1回だけ世話を選べる。正解で孵化数+1（最大+3）、3段階正解で母親の遺伝子が全開示
- 川への遠征: エビ自身が出かける。用水路（1匹〜、30分、間隔1h）／小川（2匹〜、2h、間隔4h、評判Lv2）／源流（3匹、6h、間隔12h、評判Lv3）。帰還率100%。帰還時に「遠征記録」カードをめくる。成果は小銭・素材（落ち葉・流木・石・タニシ・脱皮殻）・仲間（ワイルド個体、遺伝子非公開、★3まで）・♀は野生の♂と出会って抱卵。色ごとの得意（透明=ハズレ減、赤=仲間、青=早い、黄=カード+1、黒=拾い物、緑=危険で素材）。遠征1回で経験+1、5回で「川帰り」（価格+20%）
- バケツ: 仲間を入れる水槽がすべて満員なら「バケツ」（3匹、大きいバケツで4匹）で待機。ホームのカードから「水槽に入れる／入れ替える（水槽のエビを川に放す）／川に返す」を選ぶ。出荷や水槽購入で枠を空けてから入れることもできる。バケツも満杯のときだけ「川に残った」

## デバッグ

ブラウザのコンソールで:

```js
__ebi.hours(4)      // 4時間進める（孵化1回分）
__ebi.skip(120000)  // 2分進める
__ebi.state         // 現在の状態
__ebi.reset()       // セーブを消して最初から
__ebi.demoChest()   // 遠征記録（宝箱）の演出を見本で表示（成果は反映しない）
```
